Es soll eine Web-Anwendung entstehen, die komplett im Browser läuft und bei github später gehostet werden soll.
Ähnlich proj/grader und oned/Programmieren/Pythonkurs/Archiv/cscircles-sources online unter https://it.tbs1.de/csc.html

Im Browser läuft ein Python-Interpreter.
Auf der linken Seite kann man Python-Quelltext eingeben.
Auf der rechten Seite wird ein Klassendiagramm gezeichnet, dass genau dem Quelltext entspricht.
Das Klassendiagramm soll gemäß Standard gezeichnet werden.
Das Diagramm wird automatisch neu generiert.
Das Diagramm soll automatisch gelayoutet weden, so dass Text und Diagramm ähnlich aufgebaut sind.

Zusätzlich kann durch Kommentare im Quelltext Klarheit für bestimmte Beziehungen geschaffen werden, wenn es Doppeldeutigkeiten gibt. Etwa Aggregation oder Komposition, Interface oder abstrakte Klasse.
