Es soll eine Web-Anwendung entstehen, die komplett im Browser läuft und bei github später gehostet werden soll.
Ähnlich proj/grader und oned/.../cscircles online unter https://it.tbs1.de/csc.html
Im Browser läuft ein Python-Interpreter.

Auf der linken Seite kann man Pytho-Quelltext eingeben.
Auf der rechten Seite wird ein Klassendiagramm gezeichnet, dass genau dem Quelltext entspricht.

Zusätzlich kann durch Kommentare im Quelltext Klarheit für bestimmte Beziehungen geschaffen werden, wenn es Doppeldeutigkeiten gibt.
